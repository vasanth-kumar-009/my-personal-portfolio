Smart Supermarket Billing System

  • Tech Stack: C++, object-oriented programming,C++ file streams, text files,HTML5, CSS3, JavaScript,GitHub Pages, GitHub Actions
  • Website URL: Demo Link
  • Github URL: Project Link

Product and inventory management: Allows users to add products with their names, unit prices, and available quantities. Inventory records are stored in Bill.txt using C++ file handling.

Automated billing: Searches for products by name, calculates each purchase amount using price × quantity, and accumulates the total across multiple purchases within a billing session.

Stock updates and availability checks: Deducts purchased quantities from inventory after a successful purchase. Displays messages when a product is unavailable or the requested quantity exceeds the remaining stock.

Interactive browser demonstration: Uses Emscripten to compile the C++ application into WebAssembly, allowing visitors to operate it through a browser terminal. The interface supports typed input, scrollable output, and restarting the demo; browser inventory resets when the page reloads.
